Learning About Tags

We use Tags to give meaning to our website. Without the "p" tag for instance I wouldn't be able to display the text I am writing here.

Here is a list of some of the tags I have learned about so far, potentially for my future reference.

  • b is for use when writing BOLD text
  • i is for when one is writing italics
  • When writing a heading one should use h1. This is for main headings

  • Then when writing subheadings, one should use h2.

  • And of course to make a list you need a tag too. For this type of list you can use "ul" which makes an unordered list.
